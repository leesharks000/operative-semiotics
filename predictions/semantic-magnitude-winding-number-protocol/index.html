Measuring semantic magnitude in retrieval: the 90-day winding-number protocol

These claims set out to measure meaning in retrieval basins through the semantic magnitude M_T from the Semantic Deviation Principle, which defines a canonical work by its long-horizon divergence across fields. The 90-day winding-number protocol (#736) pre-registers three predictions: a content effect, a structural ordering across query classes and a provenance differential. EA-RESEARCH-BASIS-01 adds hypotheses that a dense, related corpus, metadata design and differentiated author-functions become machine-recognizable.
