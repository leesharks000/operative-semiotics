Semantic rent, measured: the SPXI event and position against class

Semantic Rent, Measured (#1462, August 2026) holds that rent splits into use, acknowledgment, discount and supply, that the 14 August 2026 SPXI event satisfies all four and that its acknowledgment gap is a composition choice, and specifies a retrospective scoring of the ADOPTION set. Position Is Not Class (#1465) holds, from the same address composed three weeks earlier at PER 0.25, that class belongs to the composition event and not the machine, and defines the class-traitor event; the whole-stack measurement (#1470) holds the address equally retrievable in both cases. The Assembly Synthesis (#1467) restricts supply to compositions where the source is unacknowledged, and The Measurement Stack (#1463) specifies defining Γ by resistance to all three components of ΔE.
