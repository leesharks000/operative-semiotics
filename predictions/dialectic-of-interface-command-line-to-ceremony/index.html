The dialectic of the interface: from command line to ceremony

The Dialectic of the Interface forecasts, with falsifiers, a paced-generation counter-market by 2028, explicit register thresholds, performative interfaces that officiate speech acts by 2029, and a measurable bearing premium. It names the chat window's contradiction as flatness, constative monopoly and costlessness, and the next negation as bearing rather than friction. The Mandala system is claimed as the archive's first deliberate instance of the liturgical interface.
