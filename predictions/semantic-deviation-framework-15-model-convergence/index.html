Semantic deviation and Framework 15: pre-registered tests of model convergence

These claims pre-register tests of whether machine output converges and RLHF compresses deviation. Framework 15 (#108) and its Lagrange Observatory papers (#735, #736, #737) specify the frozen 90-day retrieval-basin winding-number protocol and the deviation-optimized DPO experiment, and each states that its results deposit is owed. PRED-107.F4unbuilt testregistered 2026-05-17 in #107 · Audited Claims for the Semantic Deviation Research Program — The Glas Function: An External-Format Restatementlink
Black-box judge replacement test. A scientifically essential robustness check, directly addressing the reward-model overoptimization concerns characterized in Gao et al. 2023: train Model-Sem against Judge-A; evaluate against Judge-B (a different frozen model with different weights). If Model-Sem's uplift persists against Judge-B, the result generalizes beyond the specific judge. If it disappears, the result is judge-specific reward hacking. This test is cheap (one additional evaluation pass) and load-bearing.
